# Divyansh Sharma - Full Stack Developer Portfolio

This repository contains the source code for my personal portfolio website, showcasing my projects, skills, and experience as a Full Stack Developer. The website is built with modern frontend technologies and is designed to be highly responsive, accessible, and fast.

## 🚀 Tech Stack

- **Framework**: React.js 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Deployment**: GitHub Pages

## 🛠️ Local Development

To run this project locally on your machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/divyansharma-sys/-divyansh-sharma-portfolio.git
   cd -divyansh-sharma-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:3000/-divyansh-sharma-portfolio/`.

## 📦 Build and Deployment

This project is configured to automatically deploy to GitHub Pages.

To build the project for production:
```bash
npm run build
```

To deploy the project to the `gh-pages` branch:
```bash
npm run deploy
```

## 📁 Project Structure

- `src/components/`: Reusable UI components (Hero, Navbar, Projects, Skills, etc.)
- `src/data/`: Hardcoded portfolio data (Projects list, Skills list, Experience timeline)
- `src/assets/`: Static assets like images and fonts
- `src/utils/`: Helper functions
