# Personal Portfolio

Welcome to my personal developer portfolio, built with React, Vite, and Tailwind CSS. 

This project showcases my skills, experience, and the projects I have been working on.

## Live Site
[View My Portfolio](https://divyansharma-sys.github.io/Portfolio/)

## Tech Stack
- **Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Run Locally

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/divyansharma-sys/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be running at `http://localhost:3000`.

## Deployment
This project is automatically deployed to GitHub Pages using GitHub Actions upon pushing to the `main` branch.
